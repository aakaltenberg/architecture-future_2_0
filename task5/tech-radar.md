# Расширенный технический радар «Будущее 2.0»

**Статусы:**
- **Adopt** — рекомендовано к широкому использованию.
- **Trial** — использовать в пилотах, проверенных проектах.
- **Assess** — изучать, возможно применение в будущем.
- **Hold** — не использовать, либо прекратить использование.

## Архитектурные паттерны

| Паттерн / подход               | Статус | Обоснование                                                                 |
|--------------------------------|--------|------------------------------------------------------------------------------|
| Data Mesh                      | Adopt  | Ключевая стратегия децентрализации данных, соответствует бизнес-целям.       |
| Event-Driven Architecture      | Adopt  | Основа для интеграции доменов, замена синхронных вызовов.                    |
| Domain-Driven Design           | Adopt  | Методология выделения bounded contexts, агрегатов, событий.                 |
| Self-Service BI                | Adopt  | Портал самообслуживания, снижение нагрузки на аналитиков.                   |
| Data Contracts                 | Adopt  | Стандартизация схем событий, интерфейсов.                                   |
| Data Product thinking          | Adopt  | Каждый домен отвечает за свои данные как продукт.                           |
| CQRS / Event Sourcing          | Assess | Возможно для отдельных доменов с высокими требованиями к аудиту (финтех).    |
| Microservices                  | Adopt  | В доменных сервисах.                                                        |
| API-First                     | Adopt  | Для синхронных взаимодействий, где необходимо.                              |

## Инфраструктура и облако

| Технология                     | Статус | Обоснование                                                                 |
|--------------------------------|--------|------------------------------------------------------------------------------|
| Yandex Cloud (или AWS)         | Adopt  | Целевая облачная платформа, managed-сервисы.                                |
| Kubernetes (Managed)           | Adopt  | Оркестрация контейнеров, масштабирование.                                   |
| Terraform                      | Adopt  | Инфраструктура как код.                                                     |
| GitLab CI/CD / GitHub Actions  | Adopt  | Автоматизация развёртывания.                                                |
| Object Storage (S3)            | Adopt  | Data Lake, хранение сырых данных.                                           |
| VPC / IAM                      | Adopt  | Безопасность, изоляция.                                                     |
| On-premise SQL Server 2008     | Hold   | Выводится из эксплуатации.                                                  |

## Комментарий

Целевой стек строится на открытых технологиях и облачных managed-сервисах, чтобы избежать vendor lock-in и обеспечить масштабируемость. Легаси-компоненты (SQL Server 2008, PowerBuilder, Camel, Power BI) помечены статусом Hold и выводятся через мосты совместимости в течение 3 лет.
