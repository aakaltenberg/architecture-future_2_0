# Агрегаты доменов

## Patient Management

**Агрегат Patient**
- Ключ: `patientId`
- Границы: персональные данные, контакты, страховка, статус
- Инварианты:
  - `patientId` уникален
  - Нельзя создать пациента без имени и даты рождения
  - Статус может быть только Active/Inactive

**Агрегат Appointment**
- Ключ: `appointmentId`
- Границы: ссылка на пациента, дата/время, врач, статус
- Инварианты:
  - Нельзя записать на приём в нерабочее время
  - Нельзя перевести в статус Completed, если не был в статусе Scheduled

## Clinical Services

**Агрегат MedicalRecord**
- Ключ: `recordId`
- Границы: ссылка на пациента, диагнозы, процедуры, результаты исследований
- Инварианты:
  - Запись может быть создана только для существующего пациента
  - Нельзя добавить результат исследования без самого исследования

**Агрегат MedicalTest**
- Ключ: `testId`
- Границы: тип исследования, статус, результат (текстовый/числовой), файл (если есть)
- Инварианты:
  - Статус изменяется по цепочке: Ordered → InProgress → Completed
  - Результат обязателен при статусе Completed

**Агрегат Diagnosis**
- Ключ: `diagnosisId`
- Границы: код МКБ, описание, дата постановки
- Инварианты:
  - Диагноз привязан к конкретной медицинской записи

## AI Analysis

**Агрегат AIAnalysisJob**
- Ключ: `jobId`
- Границы: ссылка на MedicalTest, входные данные (например, изображение), результат анализа, статус
- Инварианты:
  - Статус: Submitted → Processing → Completed / Failed
  - Результат обязателен при статусе Completed

## Fintech

**Агрегат Account**
- Ключ: `accountId`
- Границы: баланс, тип счёта, владелец (ссылка на пациента/клиента)
- Инварианты:
  - Баланс не может быть отрицательным (для дебетовых счетов)
  - Нельзя закрыть счёт с ненулевым балансом

**Агрегат LoanAgreement**
- Ключ: `agreementId`
- Границы: сумма, процентная ставка, срок, статус (Draft, Active, Closed)
- Инварианты:
  - Сумма > 0
  - Статус изменяется только по цепочке Draft → Active → Closed

**Агрегат Payment**
- Ключ: `paymentId`
- Границы: сумма, счёт, дата, назначение
- Инварианты:
  - Сумма > 0
  - Платёж всегда связан с существующим счётом

## Clinic Operations

**Агрегат Equipment**
- Ключ: `equipmentId`
- Границы: тип, инвентарный номер, график обслуживания, статус
- Инварианты:
  - Статус: Available / InUse / UnderMaintenance
  - Нельзя назначить обслуживание на оборудование в статусе InUse

**Агрегат Staff**
- Ключ: `staffId`
- Границы: ФИО, должность, график, назначения
- Инварианты:
  - Один сотрудник не может быть назначен на два одновременных приёма
